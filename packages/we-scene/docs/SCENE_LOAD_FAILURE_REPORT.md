# 疑难场景加载失败分析（内部诊断记录）

> 本文件是开发期的排查记录，保留供复现与回归参考；**不代表兼容性结论**。壁纸名已匿名化。

## 一、视频纹理类场景（两个）

**症状**：加载后只剩空背景。

**根因**：场景的 `scene.json` 只有 3 个对象——一个视频纹理层（TEXV 容器内嵌 MP4，占满全屏）+ 一个粒子 + 一个声音。主视觉完全由视频纹理层构成，当时渲染器不支持视频纹理（加载时直接丢弃）。

**修复**：视频纹理层支持（MP4 字节 → `<video>` 元素 → 每帧上传 WebGL）。已修复，此类场景现已可用。

## 二、复杂 2D 场景（一个）

**症状**：渲染第一帧即抛错；后续修复后仍整体不可用（灰屏），已停止适配。

**过程记录**：
1. `effects/iris` 转译缺陷（整数字面量减 float 变量、smoothstep 整型实参）→ 已修复，编译通过；
2. 纹理 mip 链不完整（容器只存部分级，WebGL 采样恒黑）→ 已修复（generateMipmap 补齐，通用修复）；
3. 父子层级合并、场景/对象级视差已实现；
4. 用户实测仍不可用（灰屏），判定 ❌ 不兼容，停止适配。

**遗留能力**（对其他场景通用有效）：父子层级合并、cameraparallax/parallaxDepth 视差、mip 链补齐。

## 三、暴露的通用能力缺口（按优先级）

| 缺口 | 说明 |
| --- | --- |
| 视频纹理层（已解决） | 录屏类场景主视觉 |
| 粒子系统 | 樱花/碎屑/光斑装饰 |
| 文字对象 | 时钟数字、歌词 |
| 声音对象 | 背景音 |
| 3D 管线 | 3D 模型场景 |

## 四、结论

- 视频纹理类场景：已支持，可用；
- 3D 类场景：需 3D 管线，未开始；
- 个别高复杂度 2D 场景：可能仍存在未知兼容问题，实测为准。
