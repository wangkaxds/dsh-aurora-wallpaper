# 兼容性报告

判定标准：
- ✅ **完美兼容**：与 Wallpaper Engine 原生画面一致（动画、位置、效果都对）
- 🟡 **基本兼容**：主视觉完整渲染，但装饰元素（粒子/文字/声音等）缺失
- ❌ **不兼容**：无法渲染或主视觉缺失

## 一、什么类型的壁纸可以完美兼容

只要满足以下**全部**条件，基本可以做到与 WE 原生画面一致：

1. **2D 图层构成** —— 立绘、漫画、渐变横幅、平面插画类场景（objects 全是 image/solid，无 3D 模型对象）
2. **无粒子、无文字、无组件** —— 或对樱花/光斑/时钟挂件这类装饰元素无感
3. **常见 2D 效果** —— 滚动、呼吸、抖动、水波、飘动、变色、遮罩、虹膜、水流等（已覆盖 20+ 种效果 shader）
4. **常规纹理格式** —— ARGB8888 / RGB888 / RGB565 / DXT1/3/5 / RG88 / R8 / LZ4 / PNG / JPEG（全部支持）

**实测结论**：符合上述条件的纯立绘、漫画、角色壁纸已有多张达到完美兼容（动画、层级、视差全部正确）；视频录屏类场景（TEXV 内嵌 MP4 主视觉）同样完美。

## 二、基本兼容（主视觉完整，装饰缺失）

以下类型可以正常使用，但部分装饰元素不显示：

- 带**粒子系统**的 2D 场景（樱花、碎屑、光斑、灰烬）—— 粒子不渲染，其余完整
- 带**文字对象**的场景（时钟数字、歌词）—— 文字不显示
- 带**声音对象**的场景 —— 不播放背景音
- 带**鼠标视差**的场景 —— 已支持（含延迟平滑），但关键帧动画（animationlayers）不播放

## 三、不兼容

| 类型 | 说明 |
| --- | --- |
| **3D 模型场景** | mesh 模型、透视相机、骨骼/蒙皮 —— 2D 管线无法渲染，完全不可用 |
| **复杂混合场景（个别）** | 极少数高复杂度场景实测不可用（渲染异常），属已知未解决项 |

## 四、能力兼容矩阵

### ✅ 完整支持

- 视频壁纸：mp4 / webp / gif 直连播放（4K 原画、Range 流式、循环）
- 场景 2D 图层：origin / size / scale / angles、对齐、颜色、透明度、亮度、可见性
- 纯色层（solid）、清屏色、正交投影相机、图层 z 顺序
- 纹理格式：ARGB8888、RGB888、RGB565、DXT1、DXT3、DXT5、RG88、R8、LZ4、PNG/JPEG、mip 链（残缺自动补齐）
- 视频纹理层（TEXV 内嵌 MP4，录屏类场景主视觉）
- 效果链：copy → 效果 pass 链 → 合成、FBO 乒乓、效果目标缓冲、纹理槽、combo 语义（显式/默认/纹理槽 MASK）
- 效果 shader（实测通过 20+ 种）：scroll、tint、colorkey、pulse、shake、waterwaves、waterripple、foliagesway、iris、waterflow、localcontrast 系列、genericimage4 及 workshop 自定义 shader
- 父子层级（静态父级）、中文文件名（UTF-8 条目名）、鼠标视差（cameraparallax + parallaxDepth）

### ❌ 不支持

| 缺失能力 | 影响 |
| --- | --- |
| 3D 场景（mesh/透视相机/骨骼） | 3D 类壁纸完全无法渲染 |
| 粒子系统 | 樱花/碎屑等装饰缺失 |
| 文字对象 | 时钟数字、歌词不显示 |
| 声音对象 | 不播放背景音 |
| 组件（components：时钟/天气/音频可视化/幻灯片/按钮） | 不渲染、无参数面板 |
| 相机震动（camerashake） | 无震动效果 |
| 泛光后处理（bloom） | 高光不发散 |
| 关键帧动画（animationlayers） | 对象保持静态位置 |

## 五、路线图（按收益排序）

1. 粒子系统 —— 大量场景的装饰元素直接补全
2. 文字对象 —— 时钟/歌词类场景
3. 组件（时钟/天气）—— 组件类壁纸从 0 到可用
4. 声音播放 —— 低成本、体验加分
5. 3D 管线 —— 最重，3D 类场景解锁
