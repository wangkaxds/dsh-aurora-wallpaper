# 兼容性报告

判定标准：
- ✅ **完美兼容**：与 Wallpaper Engine 原生画面一致（动画、位置、效果都对）
- 🟡 **基本兼容**：主视觉完整渲染，但装饰元素（粒子/文字/声音等）缺失
- ❌ **不兼容**：无法渲染或主视觉缺失

## 二、能力兼容矩阵

### ✅ 完整支持

- 视频壁纸：mp4 / webp / gif 直连播放（4K 原画、Range 流式、循环）
- 场景 2D 图层：origin / size / scale / angles、对齐、颜色、透明度、亮度、可见性
- 纯色层（solid）、清屏色、正交投影相机、图层 z 顺序
- 纹理格式：ARGB8888、RGB888、RGB565、DXT1、DXT3、DXT5、RG88、R8、LZ4 压缩、内嵌 PNG/JPEG、mip 链（残缺自动补齐）
- 视频纹理层（TEXV 容器内嵌 MP4，录屏类场景主视觉）
- 效果链：copy → 效果 pass 链 → 合成、FBO 乒乓、效果目标缓冲（`_rt_*`）、纹理槽、combo 语义（显式/默认/纹理槽 MASK）
- 效果 shader 转译（已实测通过）：scroll、tint、colorkey、pulse、shake、waterwaves、waterripple、foliagesway、iris、waterflow、localcontrast 系列、genericimage4 及 workshop 自定义 shader
- 父子层级（静态父级）、中文文件名（UTF-8 条目名）

### 🟡 部分支持

- **鼠标视差**：`cameraparallax` + `parallaxDepth` 已实现（含延迟平滑）；`animationlayers` 关键帧动画不播放（对象保持静态位置）
- **效果覆盖范围**：常见 2D 效果全部覆盖；个别冷门效果（depthparallax、xray、lightshafts 部分特性）转译通过但未逐一对拍

### ❌ 不支持

| 缺失能力 | 影响 |
| --- | --- |
| **3D 场景**（mesh 模型、透视相机、骨骼/蒙皮） | Sora 类场景完全无法渲染 |
| **粒子系统**（樱花/碎屑/光斑/灰烬等） | 场景装饰缺失，主视觉不受影响 |
| **文字对象**（时钟数字、歌词） | 文字不显示 |
| **声音对象**（mp3） | 不播放背景音 |
| **组件**（components：时钟/天气/音频可视化/幻灯片/按钮） | 完全不渲染、无参数面板 |
| **相机震动**（camerashake） | 无震动效果 |
| **泛光后处理**（bloom） | 高光不发散（整体观感略平） |
| **3D 深度/光照特性** | 仅 2D 场景无关 |

## 三、什么样的壁纸会"完美兼容"

同时满足以下条件的场景壁纸，可达到 ✅ 完美：

1. **2D 图层构成**（objects 全部是 image/solid，无 model 3D 对象）
2. **无粒子、无文字、无组件**（或对这些装饰元素无感）
3. **效果是常见 2D 效果**（scroll/shake/pulse/水波/飘动/变色/遮罩类——已覆盖 20+ 种）
4. **纹理是常规格式**（上述 9 种全部支持）

你的工坊里，**纯立绘/漫画/渐变横幅类 2D 场景**基本都能完美；**带樱花/光斑装饰的**主视觉完整、装饰缺失；**3D 人物场景（Sora 类）**暂不支持。

## 四、路线图（按收益排序）

1. 粒子系统 —— 大量场景的装饰元素（樱花、碎屑）直接补全
2. 文字对象 —— 时钟/歌词类场景
3. 组件（时钟/天气）—— 组件类壁纸从 0 到可用
4. 声音播放 —— 低成本、体验加分
5. 3D 管线 —— 最重，Sora 类场景解锁
