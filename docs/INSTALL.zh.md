# 保姆级安装教程

> 适用：完全没接触过 DeepSeek Harness 插件的用户。跟着做，每一步都有说明和"预期结果"。

## 一、先认识这个插件由什么组成

本插件是一个 **动态 Cordis 插件**，由两半组成：

| 文件 | 作用 | 运行位置 |
| --- | --- | --- |
| `src/host.js` | 扫描壁纸目录、提供视频流、向页面注入背景层 | 服务端（Node.js） |
| `src/client.js` | 主题、玻璃纱罩、设置面板 | 浏览器页面 |

两半必须**一起**装载才会完整：只有宿主半 = 视频能播但没有玻璃纱罩和设置页；只有客户端半 = 有面板但列表是空的。

## 二、开始之前

1. 你的电脑上已经安装并**运行着 DeepSeek Harness**，且能用浏览器打开它的网页界面（默认 `http://127.0.0.1:3080`）；
2. 装有 [Wallpaper Engine](https://store.steampowered.com/app/431960/)，并且**至少下载过一个壁纸**；
3. 知道你的 Steam 库位置（默认 `D:\steam\steamapps\workshop\content\431960`，装在别处就记下实际路径）。

## 三、第 1 步：修改配置（30 秒）

用任意文本编辑器（记事本就行）打开 `src/host.js`，找到文件最上方：

```js
const CONFIG = {
  workshopDir: 'D:\\steam\\steamapps\\workshop\\content\\431960',
  vaultDir: 'D:\\aurora-wallpaper',
}
```

- `workshopDir` 改成你机器上壁纸引擎工坊目录的**真实路径**（注意反斜杠要写两个 `\\`）；
- `vaultDir` 是插件的工作目录，随便给一个存在的文件夹即可（不存在的话最好先手动建一个）；
- 保存文件。

## 四、第 2 步：把两半装进 Harness（核心步骤）

### 方法 A：交给 Harness 里的 AI 帮你装（推荐，最省事）

1. 在 Harness 网页界面里**新建一个会话**；
2. 把 `src/host.js` 和 `src/client.js` 两个文件的**完整内容**发到对话框里（拖拽文件进去即可）；
3. 对 AI 说：

   > 帮我把这两个文件作为动态 Cordis 插件装载：第一个是宿主半，第二个是客户端半。定义后运行，并告诉我结果。

4. 等 AI 完成。你会看到对话里出现 `cordis_define` 和 `cordis_run` 的执行卡片；
5. 如果弹出**批准请求**（Run 卡片上出现 ✓ 按钮），点允许（想以后免问可以给双 ✓）；
6. 看到 `completed successfully` 就说明装载成功。

### 方法 B：如果你熟悉命令行

把两个文件的函数体分别作为 `code.host` 与 `code.client` 交给 `cordis_define`，再用 `cordis_run` 激活（具体参数格式见 Harness 文档；新手建议直接用方法 A）。

## 五、第 3 步：刷新并验收

1. 在浏览器里按 **Ctrl + F5**（硬刷新）一次——背景视频注入发生在页面加载时，必须刷新；
2. 刷新后你应该看到：
   - 整个界面背后在播放你的壁纸视频（静音循环）；
   - 界面有一层半透明"雾面玻璃"质感；
3. 打开 **设置 → 壁纸背景**（侧边栏底部"设置"按钮 → 面板里的"壁纸背景"页签），你应该看到：
   - 四个主题按钮：**动态壁纸·暗**（默认高亮）/ 动态壁纸·亮 / 内置暗色 / 内置亮色；
   - 壁纸列表（自动扫描了你的壁纸引擎目录，显示真实标题）；
   - "上一张 / 下一张"按钮；
   - "同步壁纸引擎目录"按钮（装了新壁纸后点一下即可入列）；
   - "从文件夹选择"按钮（把任意文件夹里的 mp4 加进来）。

## 六、日常使用

| 想做什么 | 怎么做 |
| --- | --- |
| 换壁纸 | 设置 → 壁纸背景 → 点列表任意一项，或"上一张/下一张" |
| 换明暗风格 | 壁纸背景页里四个主题按钮 |
| 装了新壁纸 | 点"同步壁纸引擎目录"（或重启插件） |
| 记住上次的壁纸 | 自动的（存在浏览器 localStorage） |
| 彻底关掉 | 停用插件（cordis_stop），再 Ctrl+F5 刷新即完全还原 |

## 七、常见问题排查

| 现象 | 原因与解法 |
| --- | --- |
| 刷新后没视频 | 先确认插件显示"运行中"；再看是否有**多个 Harness 标签页**——多余的标签页会抢走客户端激活，关掉它们只留一个，再 Ctrl+F5 |
| 有视频但没玻璃纱罩/设置页 | 客户端半没装上（只装了宿主半）。把 `src/client.js` 重新发给 AI 装载 |
| 设置页提示"未发现壁纸" | `workshopDir` 路径不对；检查项目里是否真有含 `.mp4` 的子文件夹 |
| 视频循环处轻微卡一下 | 已知限制：浏览器对带音频轨的 4K 视频回跳需要重置渲染器 |
| 深浅不合口味 | 见 [调参指南](#八调参指南) |

## 八、调参指南

所有观感参数都在 `src/client.js` 里，改完重新装载即可（改动的都是 CSS / token 值，不必懂编程，照着改数字）：

| 想调什么 | 找哪里 | 怎么改 |
| --- | --- | --- |
| 玻璃纱罩透光度 | 主题 token `--dsw-alias-bg-base`（`#1515152E`） | 最后两位是十六进制透明度：`2E`≈18%、`59`≈35%、`99`≈60%。数字越大越不透 |
| 侧边栏深浅 | `--dsw-specific-sidebar-fill` | 同上（默认 45%） |
| 对话框深浅 | `--dsw-specific-input-major` | 同上（默认 80%） |
| 顶部渐深 | 搜 `body[data-ds-dark-theme]::after` 里第二行（`rgba(14,14,16,0.75) 0%...`） | 改 `0.75` 即可（0~1） |
| 底部渐暗 | 同一段里第一行（`rgba(14,14,16,0) 50%, ...`） | 改最后一个 `0.58`（0~1） |
| 对话框上移 | 搜 `[data-composer-seat]` | 加一行 `transform: translateY(-12px);`（负数越大越靠上） |

改完把整个 `src/client.js` 重新发给 AI："帮我更新客户端半为新内容"。

## 九、卸载

1. 在对话里让 AI 执行 `cordis_stop`（或直接 `cordis_undefine` 彻底删除）；
2. 浏览器 Ctrl+F5 刷新；
3. 删除 `vaultDir` 目录（如果有）即可，不碰壁纸引擎里的任何文件。
